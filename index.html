      Scope

      Concept, build, and deployment plan.

      The MVP is designed to be funny enough to share and concrete enough to sell into AI teams.

      Concept

      SlopCourt turns the internet's frustration with generic AI output into a participatory benchmark. Users submit content, receive a verdict, and share the card. The dataset becomes the moat.

      Build

      This version is static HTML, CSS, and JavaScript. The scoring engine is deterministic, explainable, and ready to be swapped with an LLM-backed evaluator.

      Deployment

      Ship as a static site first. Public cases are repo JSON, the docket is a generated static file, and case links work without a server.

      Deployment

      No build step. No waiting.

      Push the repo to GitHub Pages, upload it to an S3 static bucket, or serve the files from any static host. Rebuild the docket, case pages, and share cards only when public case files change.
